# Rogue (rogues21)

Консольная **roguelike**-игра на Python, вдохновлённая классическим Rogue (1980). Реализована по принципам **чистой архитектуры** с разделением на слои, интерфейс — на базе библиотеки `curses`. Проект в рамках **School 21 / Python_Bootcamp** (командный проект).

## О проекте

Игрок исследует процедурно генерируемые подземелья из 21 уровня, сражается с монстрами, собирает сокровища и предметы, продвигаясь к выходу. Игра полностью пошаговая: каждый ход игрока вызывает действия врагов на поле.

## Архитектура

Чистое разделение на слои по принципу **clean architecture** (инверсия зависимостей — domain не зависит от остальных слоёв):

- **domain** — вся игровая логика: персонаж, враги, предметы, бой, генерация подземелий, видимость.
- **presentation** — отрисовка через `curses`: поле, предметы, интерфейс, меню.
- **data (managers)** — сохранение прогресса, рекорды и статистика в JSON.
- **infrastructure** — служебное: логирование, фоновая музыка (`pygame-ce`).

## Игровые механики

- **21 уровень** подземелий; каждый уровень — 9 комнат, соединённых коридорами.
- **Процедурная генерация** комнат, секторов, коридоров и тупиков с проверкой связности графа.
- **Пошаговый бой**: проверка попадания (зависит от ловкости), расчёт урона (сила + оружие), применение урона.
- **5 типов врагов** с уникальным поведением: зомби, вампир, призрак, огр, змей-маг; бонусный — мимик.
- **Предметы**: сокровища, еда, эликсиры, свитки, оружие; рюкзак до 9 слотов на тип.
- **Атрибуты**: здоровье (макс/текущее), ловкость, сила, текущее оружие.
- **Система видимости**: туман войны (fog of war), ray casting по алгоритму Брезенхема, режимы unlimited / псевдо-3D (перспектива от первого лица) / 3D.
- **Сложность растёт** с каждым уровнем: больше и сильнее врагов, меньше полезных предметов.
- **Смерть** сбрасывает прогресс; результаты заносятся в таблицу рекордов (по количеству сокровищ).
- Динамическая подстройка сложности (бонусный режим).

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | Движение персонажа |
| `H` | Использовать оружие |
| `J` | Использовать еду |
| `K` | Использовать эликсир |
| `E` | Использовать свиток |

В 3D-режиме: `W/S` — вперёд/назад, `A/D` — поворот.

## Запуск

```bash
pip install -r requirements.txt
python src/rogues21.py            # основной режим (туман войны)
python src/rogues21.py --3d       # псевдо-3D отображение
python src/rogues21.py --all      # полная видимость
```

Флаги логирования: `--debug`, `--verbose`, `--quiet`, `--log`.

Игра собирается как пакет `rogues21` (см. `pyproject.toml`).
